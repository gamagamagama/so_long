### Usage :
```bash
git clone https://github.com/gamagamagama/so_long.git
cd so_long
```
```bash
#to install dependencies on your machine
make deps  
```
OR
```bash
#install deps
sudo apt update
sudo apt install -y cmake
sudo apt install -y build-essential libx11-dev libglfw3-dev libglfw3 xorg-dev
```
INSTALL
```bash
#Clone and Build MLX42 lib + compile so_long
make all
```
```bash
#Usage : ./so_long map_file/map[0-13 or 42].ber
./so_long map_file/map11.ber
```
### Controls:

Use `WSAD` to move , try to Hit `M` for Master Mode
